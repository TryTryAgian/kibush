# כיבוש פיקסלים

משחק אסטרטגיה בזמן אמת על מפה מפוקסלת. בלי בנייה ובלי ספריות — רק HTML, CSS ו-JavaScript.

## מבנה

```
index.html          דף המשחק (טוען את כל הקבצים לפי הסדר)
css/style.css       עיצוב הממשק
assets/sprites.png  כל הספרייטים בגיליון אחד
js/config.js        הגדרות ונתונים: CFG, מבנים, יחידות, אוגדות, עץ מחקר, אישיויות
js/atlas.js         מיקום כל ספרייט בגיליון (נוצר אוטומטית)
js/core.js          כלים, מצב המשחק, יצירת מפות, מציאת דרכים
js/economy.js       כלכלה, בנייה, ערים, רכבות
js/military.js      אוגדות, גנרלים, קרב, מבצעים, אספקה
js/diplomacy.js     הסכמים, מלחמה ושלום
js/ai.js            אומות המחשב
js/sim.js           לולאת הסימולציה
js/render.js        ציור המפה והיחידות
js/ui.js            הממשק
js/input.js         מגע, גרירה וזום
js/main.js          שמירה, טעינה והפעלה
tools/sprites.py    מחולל הגיליון הראשוני (Python + Pillow)
```

## עריכת ספרייטים

1. פותחים את `assets/sprites.png` ב-Piskel או Aseprite.
2. יחידות הן 16×16 (שתי מסגרות אנימציה זו ליד זו), מבנים 24×24.
3. צבע הקבוצה מסמנים במג'נטה — המשחק צובע אותו בצבע האומה:
   - `#ff00ff` צבע רגיל
   - `#b000b0` צל כהה
   - `#ff80ff` הארה
4. שומרים באותו שם ובאותו גודל, באותם מיקומים (הם רשומים ב-`js/atlas.js`).

אם משנים גודל או מוסיפים ספרייט — צריך לעדכן את `js/atlas.js` (`[x, y, גודל, מסגרות]`).

## הרצה

- **GitHub Pages:** מעלים את כל התיקייה לריפו ומפעילים Pages. זה הכול.

  עדיף שרת קטן: `python3 -m http.server` בתוך התיקייה, ואז http://localhost:8000
